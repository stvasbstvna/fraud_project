# Published project and local research assets

This GitHub snapshot contains implementation, exact prompts/configurations, reports, figures, plotting data and rights-reviewed v3/v3.2 research evidence. Current visual results: [available-pair gallery](results/benchmark_v3_2/FIGURE_GALLERY.md). Scientific limitations remain unchanged: the v3.2 primary complete-trajectory experiment did not achieve completeness.

Local Python environments, external dataset checkouts, caches, archives and binary model weights are not uploaded. Model identity, configurations and hashes are retained as metadata; a fresh clone does not contain the frozen weights required for inference. Reproduction requires the corresponding local assets described in the runbooks.

Newly untracked historical message-level exports whose redistribution rights were not established, including SmishTank-derived final data, are intentionally omitted. Their import/evaluation code, aggregate observations, documentation and applicable existing tracked files remain separate from newly uploaded raw records. Availability in a public paper does not establish a data redistribution grant.

For the v3/v3.2 source artifacts, retain the original attribution and applicable notices: Mendeley/UCI CC BY4.0, Gateway MIT data-release notice, and NUS authors' unlimited-use declaration. See [source rights audit](docs/benchmark_v3/SOURCE_LICENSE_AUDIT.md), [v3.2 source expansion](docs/benchmark_v3_2/SOURCE_EXPANSION_AUDIT.md), and [existing attribution](data/ATTRIBUTION.md). Upstream rights are not replaced by the project repository's license.

No API credentials or `.env` files are part of this publication. Exact API research receipts contain minimized public-source research inputs and provider outputs, not authentication headers. Files below `.git/publication` are local staging audit records and are not committed.

The repository attributes preserve exact bytes for versioned research artifacts and prompts. Git must not silently normalize their line endings because frozen SHA-256 evidence includes those bytes.
